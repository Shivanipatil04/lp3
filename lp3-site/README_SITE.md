## 🚀 Quick Start (Opening the Site)

This is a **100% offline static website** requiring **no server, no backend, and no internet connection**.

### Method 1: Double-Click
Simply double-click `lp3-site/index.html` in your file explorer. It will open directly in any browser (Chrome, Edge, Firefox, Brave) via the `file://` protocol.

### Method 2: Linux Terminal
```bash
cd lp3-site
xdg-open index.html   # or google-chrome index.html / firefox index.html
```

## 🔄 How to Rebuild `js/data.js`

Whenever source code in `lp3-final/` is updated, run the build script to regenerate `js/data.js` and verify SHA-256 checksums:

```bash
cd lp3-site
python3 build.py
```

The script will:
1. Read the authentic files from `lp3-final/`.
2. Compute SHA-256 hashes.
3. Generate `js/data.js` with byte-identical code strings.
4. Verify checksum integrity.
